# Vice City Cover Studio

Turn your photo and a caption into GTA 6-style poster cover art — multi-panel,
bold caption lettering, sunset Vice City / neon grade — and export it as a PNG
to share (1080×1080, 1080×1350, 1920×1080).

## How it works

Open `app/index.html` in desktop Chrome (or run `node serve.ts` and open
http://localhost:8080). Upload your own photo, crop and position it across
several poster panels, write and edit the caption, then export a PNG in the
post size you want. Everything runs locally in the browser — no network, no
upload.

All artwork is original: no Rockstar logos, wordmarks, artwork, characters or
fonts. Fonts shipped under `app/` are SIL Open Font License.
